# 教案 Word 版式与结构规则

本规则由「机械与动力工程学院」多门课程教案 DOCX 按 **并集蒸馏** 得到，描述**输出 Word 的结构约束**，不保存任何真实课程数据。它的可执行形态是空白样式模板 `assets/lesson-plan-master.docx`（渲染器加载它排版权），本文件是版式的文字说明。与「语言规则」共享证据分层：`stable-core` 为多份一致、`conditional-variant` 为按课程类型取舍、`unresolved-conflict` 不得由编译器静默决定。

## 1. 证据分层

- `stable-core`：多份教案一致的结构与版式。
- `conditional-variant`：只适用于理论 / 实验 / 上机 / 实践 / 项目等某一类课次，或只在部分课程出现。
- `unresolved-conflict`：样例互相冲突且缺少更高优先级依据；编译时不得静默选择，应报告并等待确认。
- 旧版或异构教案可用于抽取课程内容，但不能覆盖用户指定的批注权威版式。

「已覆盖」采用并集：规则在某一份参考教案中出现即算覆盖，不要求全部同时出现。

## 2. 页面与字体（stable-core）

- A4 纵向：210 × 297 mm。
- 页边距：上约 19 mm、下约 23 mm、左约 25 mm、右约 20 mm（样例实测，存在 ±2 mm 浮动）。
- 封面主标题「教 学 设 计」：华文中宋、56 pt、粗体、居中，字符间加空格。
- 「教 务 处 制」与日期：华文中宋、16 pt、居中。
- 节标题（如「课程基本信息」）：宋体 / 黑体、16 pt、粗体。
- 正文中文宋体、西文 Times New Roman；正文 10.5 pt（五号），表格文字 9 pt、可降至 8 pt，但不得小于 8 pt。
- 表头加粗并水平、垂直居中；表格使用黑色单线边框、白色底色，不引入装饰性色彩。
- 表内标签（章节、周次、教学目标等）通常加粗并居中；内容单元格左对齐或两端对齐。

## 3. 稳定结构（stable-core）

一份完整教案 Word 由三部分组成，顺序固定：

1. **封面**（教学设计）：主标题 + 7 行信息表 + 「教务处制」+ 制定日期。
2. **课程基本信息**：16 行课程信息表 + 5 条填表说明（注）。
3. **教学单元**：每个教学单元一张表，一学期有 N 张（N = 课次数量）。

如果某课程没有实验 / 上机等环节，相应学时字段写 0，不删除整行；但不得为凑齐所有课程类型而编造课时。

## 4. 封面（stable-core）

- 主标题「教 学 设 计」。
- 7 行 × 2 列信息表，左列标签、右列内容：学院、专业（教研室）、课程名称、主讲教师、职称、授课学期、授课专业。
- 表后居中「教 务 处 制」，下一行居中日期（如「2024年9月」）。
- 封面后分页，进入课程基本信息。

## 5. 课程基本信息（stable-core）

16 行表格，字段依次为：

1. 课程名称（中文）
2. 课程名称（英文）
3. 课程类别、课程性质、授课语言（一行三组）
4. 授课学期、学分（一行两组）
5. 课程学时及分配（表头：总学时、理论、实验/上机、实习、其他）
6. 课程学时及分配（数值行，与上行首列纵向合并）
7. 适用专业
8. 教材
9. 授课学院
10. 先修课程
11. 后续课程
12. 考核类型
13. 考核形式
14. 考核方式
15. 总评成绩比例
16. 课程简介（可分段：课程基本定位 / 学时组织 / 核心学习结果 / 主要教学方法）

表格后附 5 条「注：」说明（课程类别、课程性质、授课语言、集中实习记学时方式、括号选项打√）。课程名称以培养方案等正式来源为准；未确认字段不得进入最终 Word。

## 6. 教学单元表（stable-core）

每张教学单元表 5 列、约 20 行，行顺序固定：

| 行 | 左标签 | 内容区 |
|---|---|---|
| 0 | 章节 | 第 X 章 + 授课题目（标题横跨第 4–5 列） |
| 1 | 周次 | 第 X 周（第 X 次课）+ 课时安排 |
| 2 | 知识脉络图 | 内容横跨第 2–5 列 |
| 3 | 教学目标 | 知识 / 能力 / 价值目标 |
| 4 | 课程思政 | 内容 |
| 5 | 专创融合 | 内容（无则写「无」或省略） |
| 6 | 教学重难点 | 教学重点 / 教学难点 |
| 7 | 教学方法 | 列举 |
| 8 | 教学用具 | 列举 |
| 9 | 教学设计 | 时间分配链 |
| 10 | 教学过程 | 表头行「教学步骤及主要教学内容｜设计意图」 |
| 11–17 | 课前任务 / 互动导入 / 传授新知 / 过关检测 / 课堂小结 / 作业布置 / 考勤 | 内容（横跨 2–4 列）＋ 设计意图（第 5 列） |
| 18 | 课后 教学反思 | 内容横跨 2–5 列 |
| 19 | 本章节 参考文献 | 内容横跨 2–5 列 |

- 多页表格必须重复表头；行不得任意拆开导致标签与内容分离。
- 教学过程七步为默认固定结构；「互动导入」与「传授新知」分行（部分样例合并为一行，属 conditional-variant）。
- 知识脉络图可为空；不得为凑结构编造内容。

## 7. 终稿清洁门禁（stable-core）

最终 DOCX 必须同时满足：

- 无 Word 批注和批注引用；
- 无插入 / 删除 / 移动修订节点；
- 无隐藏文字或 Web 隐藏文字；
- 无「[待填写]」「to_confirm」等未解决占位符；
- 无「由 AI 生成」「ChatGPT 生成」「Codex 生成」「模型生成」等作者或工具署名；
- 允许正常课程内容中出现「人工智能」「AI 算法」等学科术语；
- 文档属性不得写入生成模型、聊天工具或本地用户名。

## 8. 视觉复核

生成后渲染全部页面检查：标题层级、表头重复、跨页行、孤立标题、过小字号、溢出、空白页、封面与签批区。只对本次修改影响范围做重点复核；终稿必须执行基础清洁门禁。
