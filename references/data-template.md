# 教案数据模板（字段与来源转化契约）

本模板是教案的**数据字典**：定义每张表要填哪些项目、每个项目是什么、怎么填、从哪来、注意什么。它与另外两份规则正交：

| 轴 | 文件 | 决定什么 |
| --- | --- | --- |
| 样式模板 | [word-layout-rules.md](word-layout-rules.md) | 排版与可见表单格式（页面、字体、表格结构） |
| **数据模板** | 本文件 | 每张表的项目名称、填写特点、注意事项，以及「其他教学资料如何转化进来」 |
| 语言规则 | [language-style-rules.md](language-style-rules.md) | 措辞与句式（怎么写） |

只有同时满足「数据对、语言对、版式对」，才输出标准教案。

## 1. 来源角色（证据角色）

每个字段的「来源与转化」引用以下角色，与工作 Markdown 的「来源清单」一致：

| 角色 | 含义 | 能否进正式 Word |
| --- | --- | --- |
| `official_syllabus` | 课程大纲 / 培养方案给出的权威课程事实 | 能 |
| `official_training_program` | 培养方案的权威培养约束 | 能 |
| `provided_course_material` | PPT、教材、讲稿、参考资料等课程素材 | 能（经归纳后标 `derived`） |
| `reference_lesson_plan` | 参考教案样例 | 只能作格式/措辞参考，事实不得照搬 |
| `conversation_input` | 用户在对话中临时补充的事实 | 能（需确认） |
| `derived` | 由教师或生成器根据上述材料归纳的内容 | 能（须可追溯依据） |
| `to_confirm` / `not_applicable` | 缺项 / 不适用 | 不能 |

**转化总则**：官方字段直接填入并标 `official`；素材字段必须「归纳 → 派生」并保留依据，不得把参考教案的某一句照抄成事实；来源未提供的字段标 `to_confirm`，不猜测补齐。

## 2. 封面表字段（7 行）

| 项目名称 | 语义 | 填写特点 | 来源与转化 | 注意事项 |
| --- | --- | --- | --- | --- |
| 学院 | 开课学院 | 全称，如「机械与动力工程学院」 | 教务信息 / `conversation_input` | 与「授课学院」一致 |
| 专业（教研室） | 专业或教研室 | 全称 | 培养方案 `official_training_program` | 写专业名，不是教研室缩写 |
| 课程名称 | 课程中文名 | 全称，含书名号如《机械测试技术》 | 大纲 `official_syllabus` | 以培养方案/大纲为准，不自行改名 |
| 主讲教师 | 授课教师姓名 | 实名 | `conversation_input` | 不用「某某老师」占位 |
| 职称 | 教师职称 | 讲师/副教授/教授等 | `conversation_input` | 不虚构 |
| 授课学期 | 开课学期 | 如「第四学期」 | 培养方案 `official_training_program` | 与课程基本信息「授课学期」一致 |
| 授课专业 | 适用专业 | 可多个，顿号分隔 | 培养方案 `official_training_program` | 与课程基本信息「适用专业」一致 |

另含「制定日期」：居中写年月（如「2025年9月」），来源 `conversation_input`。

## 3. 课程基本信息字段

| 项目名称 | 语义 | 填写特点 | 来源与转化 | 注意事项 |
| --- | --- | --- | --- | --- |
| 课程名称（中文） | 同封面 | 全称 | 大纲 | 与封面一致 |
| 课程名称（英文） | 英文名 | 首字母大写规范 | 大纲 | 缺则标 `to_confirm` |
| 课程类别 | 通识教育类/学科基础类/专业类 | 三选一 | 培养方案 | 只填三者之一 |
| 课程性质 | 选修/必修 | 二选一 | 培养方案 | 只填二者之一 |
| 授课语言 | 中文/英文/其他语种 | 填一种 | 大纲/培养方案 | 默认中文 |
| 授课学期 | 开课学期 | 如「第四学期」 | 培养方案 | 与封面一致 |
| 学分 | 数值 | 阿拉伯数字 | 大纲/培养方案 | 与总学时匹配，不一致要核实 |
| 总学时 | 数值 | 阿拉伯数字 | 大纲 | 是理论+实验/上机+实习+其他之和 |
| 理论学时 | 数值 | 0 或正整数 | 大纲 | 求和须等于总学时 |
| 实验/上机学时 | 数值 | 0 或正整数 | 大纲 | 实验与上机可合并一栏 |
| 实习学时 | 数值 | 0 或正整数 | 大纲 | 集中实习类以周为单位（见注4） |
| 其他学时 | 数值 | 0 或正整数 | 大纲 | 无则 0 |
| 适用专业 | 专业名 | 可多个 | 培养方案 | 与封面「授课专业」一致 |
| 教材 | 选用教材 | 标准引用：作者，《书名》[M]. 出版地：出版社，年份。 | 大纲/教材封面 | 教材列第一，后续列参考资料 |
| 授课学院 | 开课学院 | 全称 | 教务信息 | 与封面「学院」一致 |
| 先修课程 | 前置课程 | 课程名顿号分隔 | 培养方案 | 无则写「无」 |
| 后续课程 | 后续课程 | 课程名顿号分隔 | 培养方案 | 无则写「无」 |
| 考核类型 | 考试课/考查课 | 二选一，括号打√ | 大纲 | 保留「（√）/（ ）」格式 |
| 考核形式 | 闭卷/开卷/笔试/机试/口试/其它 | 多选打√ | 大纲 | 保留括号打√格式 |
| 考核方式 | 作业/报告/随堂测验/阶段测验/论文/设计/作品/线上考试/线下考试/其它 | 多选打√ | 大纲 | 保留括号打√格式 |
| 总评成绩比例 | 总评公式 | 如「总评成绩 = 平时×30% + 实验×10% + 期末考试×60%」 | 大纲/考核方案 | 各权重合计 100% |
| 课程简介 | 四段：课程基本定位/学时组织/核心学习结果/主要教学方法 | 分段成文，每段一个主题 | 大纲「课程简介」+ 教材目录归纳 | 不写教师身份、不写「本课程旨在」空话 |

## 4. 教学单元字段（每课次）

| 项目名称 | 语义 | 填写特点 | 来源与转化 | 注意事项 |
| --- | --- | --- | --- | --- |
| 章节 | 本课对应的章/节 | 如「第一章 第1节」 | 大纲「教学单元」+ 教材目录 | 名称表达教学目标，不机械复制教材章节名 |
| 授课题目 | 本课主题 | 概括一句话 | 大纲单元名 / 教材节名归纳 | 与「章节」区分：章节是位置，题目是主题 |
| 周次 | 第几周第几次课 | 如「第1周（第1次课）」 | 校历 + 大纲单元序号 | 按学期日历排布，连续不跳号 |
| 课时安排 | 时长与类型 | `2课时（100 min）；类型：理论2` | 大纲学时分配 | 类型取 理论/实验/上机/实践/项目 |
| 知识脉络图 | 本课知识主线 | 三到四层「基础认知 ↓ 核心内容 ↓ 应用提升」，可加时间轴/框图 | PPT/教材章节结构归纳 `derived` | 无真实脉络可空，不编造 |
| 教学目标 | 知识/能力/价值三组 | 每组（1）（2）（3），详见语言规则 §2 | 大纲「课程目标」拆分到本课 `derived` | 具体到本课，不照抄整门课程总目标 |
| 课程思政 | 思政融入点 | （1）结合…（2）通过…，详见语言规则 §3 | 教师编写 / 参考教案 `derived` | 锚定本课技术内容，不用口号 |
| 专创融合 | 双创融入点 | 围绕…比较…改进建议，详见语言规则 §4 | 教师编写 `derived` | 无切入点可省略，不硬凑 |
| 教学重难点 | 重点 + 难点 | 「教学重点：…；教学难点：…」 | 教材 + 教师判断 `derived` | 难点写「为什么难」，不是再列一遍知识点 |
| 教学方法 | 教法列举 | 逗号分隔、以「法」结尾 | 课次类型派生 `derived` | 按理论/实践课取舍 |
| 教学用具 | 教具列举 | 起头「电脑、投影仪、多媒体课件、教材」+ 专用工具 | 课次类型派生 `derived` | 写真实会用的，不堆砌 |
| 教学设计 | 时间分配链 | 七环节箭头链，分钟合计 = 课时总长 | 教师安排 `derived` | 传授新知占大头（60–75 min） |
| 教学反思 | 课后反思 | 【教师】+ 教学流程/内容/参与/改进四方面 | 课后教师填写 `derived` | 生成时可预填框架，留待课后修订 |
| 参考文献 | 本课参考资料 | 教材列第一，分号分隔 | 教材/参考资料 `provided_course_material` | 无则写「无」，不虚构文献 |

## 5. 教学过程七步

固定七步，每步在 Word 中占一行，内容用 `<br>` 分行，右侧填「设计意图」。

| 教学步骤 | 填写特点 | 来源与转化 | 注意事项 |
| --- | --- | --- | --- |
| 课前任务 | 【教师】布置预习要点；【学生】阅读+梳理+带问题进课堂 | 教材对应内容 `provided_course_material` | 明确教材页码/概念范围 |
| 互动导入 | 【教师】复习回顾/现场演示/追问；【学生】参与问答 | PPT 导入页/案例 `provided_course_material` | 控制在课时分配内 |
| 传授新知 | 一、二、三…分知识点；每点【教师】讲原理+【学生】随堂练+【课堂强化】 | PPT 正文 + 教材章节 `provided_course_material` | 是七步中内容最多的一步 |
| 过关检测 | 【教师】选择题/判断题/简答题；【学生】作答互查；【教师】点评 | PPT 练习题 / 教师编 `derived` | 覆盖本课重难点，不超纲 |
| 课堂小结 | 【教师】关键问题/主线/方法/易错点 | 本课归纳 `derived` | 四条对应语言规则 §8 |
| 作业布置 | 【教师】课后任务 + 【要求】写思路 | 教材习题 / 教师编 `derived` | 要求写思路不只写结果 |
| 考勤 | 【教师】学习通/点名签到 | — | 固定句式，1–2 min |

## 6. 来源 → 字段总映射表

| 教学资料 | 可供给的字段 | 转化规则 |
| --- | --- | --- |
| 课程大纲 | 课程名称（中/英）、学分、总/分项学时、考核类型/形式/方式、总评比例、课程简介、教学单元（章节/题目/学时） | 直接 `official`；「课程目标」拆到每课次的「教学目标」标 `derived` |
| 培养方案 | 课程类别、课程性质、授课学期、适用专业、授课学院、先修/后续课程、毕业要求指标点 | 直接 `official`；指标点可进入「教学目标」能力目标依据 |
| 教材 | 教材引用、章节结构、知识点、例题、习题 | 章节→「章节/授课题目」，知识点→「知识脉络图/传授新知」，习题→「过关检测/作业」 |
| PPT | 知识脉络、导入案例、正文结构、练习题、配图 | 归纳为「知识脉络图/互动导入/传授新知/过关检测」，标 `derived` |
| 参考资料 | 参考文献、补充案例、最新应用 | 进「参考文献」或「课程思政/专创融合」素材，标 `derived` |
| 参考教案 | 格式与措辞 | 只作格式/语言参考，事实不得照搬 |
| 校历 | 周次 | 按学期排布课次周次 |

## 7. 缺项处理

- 来源未提供的字段标 `to_confirm`，写入 `# 编制信息 → 缺项与冲突`，并在编译前由用户确认；不得猜测补齐。
- 不适用字段（如无实验的课程）写 `not_applicable` 或学时写 0，不删除整行。
- `reference_lesson_plan` 提供的事实一律不得直接进入正式内容，必须回到大纲/培养方案核验。

## 8. 机器校验投影

`scripts/lesson_plan.py` 中的必填字段清单（`COURSE_REQUIRED`、`LESSON_REQUIRED_FACTS`、`PROCESS_STEPS`）是本数据模板的机器可读投影。字段名拼写错误会导致该字段被静默丢弃：必填字段由 `check` 报「缺失」拦截；非必填字段（知识脉络图、专创融合等）请在 `check` 报告中核对字段名与模板一致。
