# 教案语言规则

本规则由「机械与动力工程学院」2025 版、2025–2026 学年多门课程教案（机械测试技术、3D 打印技术、机械控制工程、微机原理及接口技术、智能制造导论、智能制造装备、人工智能技术及应用、专业英语、机电传动控制、计算机智能控制系统、专业导论）交叉蒸馏而成。它描述**语言层**的稳定模式与条件性变体，不保存任何真实课程内容或教师身份信息。

证据分层与「Word 版式规则」一致：`stable-core` 为多份教案一致的模式，`conditional-variant` 为只在部分课程类型出现、需按课程实际取舍的写法。**不要逐字套用某一份教案**：目标是满足全体教案的共同语言契约，而不是复刻单个案例。

## 1. 总原则（stable-core）

- 全文用规范书面中文；专业术语、器件名、软件名（如 Keil、Proteus、80C51、DDC、PLC）保留通用写法。
- 角色动作用「【教师】」「【学生】」标记；任务要求用「【要求】」；讲解中的强化点用「【课堂强化】」「【课堂互动】」。
- 引用教材主线或课程学习主线时用方括号锚定，如「围绕[……学习主线]」「结合[……]」。
- 用「（1）（2）（3）」或「1. 2. 3.」分层编号；同一条目内先结论后解释。
- 不使用「同学们大家好」「接下来我们看」等口语开场白；不使用「综上所述」等空话；不写教师身份、邮箱、水印。

## 2. 教学目标：知识 / 能力 / 价值三段式（stable-core）

每节课的「教学目标」必须分三组，每组用「（1）（2）（3）…」编号：

- **知识目标**：以「掌握 / 理解 / 了解 / 熟悉 / 能够准确说清」开头，落到具体概念、结构、原理或方法，并加一句可检验的说明，如「能够把教材知识与控制任务、程序实现或仿真现象联系起来」。
- **能力目标**：以「能够 + 行为动词（识别 / 分析 / 完成 / 判断 / 解释 / 修正 / 建立 / 梳理）」开头，点明载体与输出，例如「能够围绕[……主线]识别本次课涉及的硬件资源、程序结构和关键控制条件」「能够结合课堂案例，对[……]进行判断、解释或修正」。
- **价值目标**：落到工程意识、职业素养与作风，常见句式「树立……意识」「形成……习惯」「逐步养成……基本作风」。

三组目标都要**具体到本节课**，不得照抄上一节或整门课程的总目标。能力目标避免「提高动手能力」这类不可检验的表述。

## 3. 课程思政（stable-core）

- 通常两条：「（1）结合……场景 / 案例，引导学生理解……的支撑作用 / 现实意义」「（2）通过……错误 / 失效 / 责任案例，强调……意识与……责任态度」。
- 思政点必须**锚定本节课技术内容**（程序错误、接线错误、测量误差、国产化成果、工程安全等），不使用「培养爱国精神」等脱离内容的口号。
- 允许出现「人工智能」「AI 算法」等学科术语作为正常课程内容；不得出现「由 AI 生成」等作者署名。

## 4. 专创融合（conditional-variant）

- 常见句式：「围绕[……主线]组织学生比较不同……方案，鼓励学生从功能达成、资源占用、可读性、可靠性等角度提出改进建议」。
- 也可写成「通过分析……流程，引导学生结合……技术，探索……在……中的创新应用，培养……的双创思维」。
- 无真实创新切入点时可省略，不强行凑「创业」内容。

## 5. 教学重难点（stable-core）

- 用「教学重点：……」「教学难点：……」两行分别列写，多个要点用分号分隔。
- 重点写「是什么」：核心概念、关键结构、主要方法。
- 难点写「为什么难」：把原理落实到操作/计算/调试的具体步骤，常见句式「如何把……落实到……的具体步骤中」。

## 6. 教学方法与教学用具（stable-core）

- 教学方法：逗号分隔、以「法」结尾的列举，如「讲授法、问答法、案例分析法、程序阅读法、板书推导法、课堂检测法」。按课程类型取舍（推导类加「电路推导法」「公式推导法」，实践类加「实操演练法」「分组研讨法」）。
- 教学用具：逗号分隔的名词列举，起头固定「电脑、投影仪、多媒体课件、教材」，再按课程补充专用工具（实验箱、示波器、寄存器表、程序片段、时序图等）。

## 7. 教学设计：时间分配链（stable-core）

- 用箭头链写清流程与分钟数，总时长须与「课时安排」一致（通常 100 min）：
  `课前任务→互动导入（Xmin）→传授新知（Y min）→过关检测（10 min）→课堂小结（3–5 min）→作业布置（1–3 min）→考勤（1–2 min）`。
- 各环节分钟数相加必须等于该次课总时长；「传授新知」通常占大头（60–75 min）。

## 8. 教学过程：七步结构（stable-core）

固定七步：**课前任务 → 互动导入 → 传授新知 → 过关检测 → 课堂小结 → 作业布置 → 考勤**，另加「课后教学反思」与「本章节参考文献」。

- **课前任务**：「【教师】1. … 2. …」布置预习（明确教材对应内容、关键概念或操作要点）；「【学生】1. … 2. …」说明学生行为；结尾「带着问题进入课堂」。
- **互动导入**：「【教师】1. 复习回顾 … 2. 现场演示 / 案例引入 … 3. 追问学生……」；「【学生】参与问答、观察案例……明确本次课任务目标」。
- **传授新知**：按「一、二、三、…」或「1、2、3、…」分知识点；每个知识点下「【教师】讲清……不只告诉学生『是什么』，更强调『为什么这样、错了会出现什么现象』」+「【学生】围绕[……]进行随堂判断、……力求把教师讲解转化为自己的操作路径」；收尾可加「【课堂强化】」。
- **过关检测**：「【教师】布置课堂小测 1.【选择题】… 2.【判断题】… 3.【简答题】…」；「【学生】独立作答、同伴互查……」；「【教师】根据作答情况集中点评……」。
- **课堂小结**：「【教师】简要总结 1. 本次课解决的关键问题是…… 2. 需要重点掌握的主线是…… 3. 最值得带走的方法是…… 4. 需要警惕的易错点是……」。
- **作业布置**：「【教师】布置课后任务 1. … 2. …」+「【要求】作业不只要求写出结果，更要求写出关键思路……」。
- **考勤**：「【教师】利用学习通 / 课堂点名完成签到……」。

每步的「设计意图」栏用「通过……让学生……，同时 / 针对……，培养……」句式，说明该环节的认知作用，不与教学内容重复。

## 9. 课后教学反思（stable-core）

「【教师】课后重点从以下方面进行教学反思：」后按固定四方面编号：

1. 教学流程：导入是否带入问题情境、推进是否由浅入深；
2. 教学内容：原理/操作/现象是否讲清讲透，学生是否停留在机械记忆；
3. 学生参与：参与是否均衡、是否存在「会听不会做」「会做不会说」、薄弱学生是否得到指导；
4. 教学改进：后续是否需要增加示范、演示、对比或错例归纳。

反思要落到本节课的具体内容与手段，不写成通用套话。

## 10. 参考文献（stable-core）

- 「选用教材」列第一，其后为其他参考书目与学习资料；用分号分隔。
- 教材写标准引用样式：「作者，《书名》[M]. 出版地：出版社，年份。」。
- 无额外资料时写「无」，不虚构文献。

## 11. 条件性变体与禁止项

- 课时安排标注存在变体：「2课时（100 min）；类型：理论2」「2课时（100 min）」「2课时（100min）」。默认统一为「2课时（100 min）；类型：理论2」，实践/实验课次把「理论2」换成对应类型。
- 「互动导入」与「传授新知」在部分教案合并为一行、部分分行；默认分行，合并仅在用户明确要求时使用。
- 知识脉络图可为空（部分课次确实无图）；不得为凑字数编造脉络。
- 禁止项：占位符「[待填写]」「to_confirm」进入最终内容；AI/工具署名；真实教师姓名、职称之外的身份信息；学生姓名、学号、成绩。
