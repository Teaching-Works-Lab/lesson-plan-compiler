#### 教学过程

| 教学步骤 | 主要教学内容 | 设计意图 |
|---|---|---|
| 课前任务 | 【教师】1. …<br>【学生】1. … | 通过课前预习让学生…… |
| 互动导入（10min） | 【教师】1. …<br>【学生】…… | 从学生熟悉的场景切入，降低学习门槛。 |
| 传授新知（共70 min） | 一、…<br>【教师】……<br>【学生】围绕[……]进行……<br>【课堂强化】…… | 按「概念→作用→组成→内容→趋势」逻辑展开讲授。 |
| 过关检测（10 min） | 【教师】1.【选择题】…<br>2.【判断题】…<br>3.【简答题】…<br>【学生】独立作答、同伴互查。 | 及时检验掌握情况，针对易错点强化讲解。 |
| 课堂小结（5 min） | 【教师】1. 本次课解决的关键问题是……<br>2. 需要重点掌握的主线是…… | 梳理知识脉络，形成完整认知框架。 |
| 作业布置（3 min） | 【教师】1. …<br>【要求】不只写结果，更要写思路。 | 巩固本节知识，为下一节做预习铺垫。 |
| 考勤（2 min） | 【教师】利用学习通/课堂点名完成签到。 | 掌握出勤情况，保障教学秩序。 |
